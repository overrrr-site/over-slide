# Product Direction Decision (2026-03-05)

## Core Value Proposition
「会話で引き出す → スライドに仕上げる」の一気通貫

## Key Decisions
1. **Brainstorm modes**: Remove manual switching → AI auto-transitions through 4 phases
2. **Brief sheet**: Add reasoning_chain, rejected_alternatives, key_expressions + separate discussion_note
3. **Documents**: De-prioritize (Claude direct is better)
4. **Slides**: Template-rich hybrid (pre-designed templates + AI content filling)

## Slide Template Strategy
- Build ~20 layout types with 2-3 variations each
- Process: Human defines types → AI generates HTML drafts → Human curates → Fixed templates
- AI role changes from "generate HTML from scratch" to "select template + fill content"

## Priority Order
1. Brainstorm mode auto-transition
2. Brief sheet expansion + discussion note
3. Slide template system
4. Context handoff (brief → structure → details → design)
